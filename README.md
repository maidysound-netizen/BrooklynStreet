# MAN'S WAR: KINGS ST.

브루클린에서 영감을 받은 가상의 도시 "킹스 스트리트"를 배경으로 한 브라우저 3D FPS 게임 (Three.js).

> 모든 인물·크루·사건은 허구이며 실제 지역·단체와 관계없습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. (Three.js를 CDN에서 불러오므로 인터넷 연결 필요)

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 |
| Shift | 달리기 |
| Space | 점프 |
| 마우스 | 시점 |
| 좌클릭 / 우클릭 | 사격 / 정조준 |
| R | 재장전 |
| Q / 1~4 / 마우스 휠 | 무기 교체 (소총 · 샷건 · 리볼버 · 칼) |
| C | 크루 관리 (이름·색, 동료 영입) |
| E | NPC와 대화·퀘스트 받기 / 보데가 가게 열기 / 자전거 타기·내리기 |
| 1 2 3 (대화 중) | 대화 선택지 고르기 |
| F | 손전등 켜기/끄기 (밤에는 자동으로 켜짐) |
| Esc | 일시정지 |

쓰러진 적이 떨어뜨린 노란 상자는 탄약, 초록 상자는 체력입니다.

## 게임 목표

라이벌 크루 3개(레드 후드 · 아이언 재킷 · 틸 킹스)를 몰아내고 킹스 스트리트의 9개 구역을 점령한 뒤, 킹스 브리지 아래에 나타나는 보스 3명을 쓰러뜨리면 "킹스 스트리트 통일" 엔딩입니다.

- 평판으로 동료를 영입하고(C), 보데가에서 보급품을 사세요(E).
- 피자집에서 배달 일을 받을 수 있어요.
- 총을 많이 쏘면 경찰이 출동합니다. 숨거나 지하철로 따돌리세요.
- 밤에는 적의 시야가 짧아지지만 손전등을 켜면 들키기 쉬워요.
- 지하철 노선도에서 내 구역 역으로 순간 이동할 수 있어요.
- 지하철 입구 옆 자전거 🚲를 타면 두 배 빠르게 달려요. 대신 타는 동안엔 총을 못 쏘고, 총에 맞으면 떨어져요.

## 퀘스트

머리 위에 노란 `!`가 뜬 사람에게 말을 걸면 퀘스트를 받아요. 지금 할 일은 화면 왼쪽 위에, 목표 위치는 노란 빛기둥과 미니맵의 노란 마름모로 보여요.

1. **피자가게의 부탁**: Ember Hill의 미쉘을 쓰러뜨리고 구역을 차지하면 🔫 리볼버를 받아요. 거절해도 되지만, 하루가 지나면 미쉘이 가게를 습격해요.
2. **코치의 훈련**: 빅 로니의 훈련 3단계(달리기 · 사격 · 실전)를 하나 끝낼 때마다 최대 체력 +20.
3. **도둑맞은 자전거**: 빨간 자전거를 되찾아 오면 모든 자전거가 20% 빨라져요.
4. **지하실의 핑크빛**: 수상한 정보상 루의 부탁… 끝이 좋지 않아요.
5. **부두의 벽돌공**: 밤에만 나타나는 "모르타르" 마일로. 그 창고 밑에는…

이야기 전체는 [STORY.md](STORY.md)에 있어요.

## 크루 불만

동료가 쓰러지거나 구역을 잃거나 한동안 아무 일도 없으면 불만이 쌓여요(화면 왼쪽 아래 😠, 크루 화면의 막대). 100%가 되면 라이벌 크루로 넘어가서 **배신자**로 나타나요. 전쟁에서 이기거나 보데가에서 **크루 간식**을 사 주면 풀려요.

## 미니맵

초록 `$`는 보데가(흐리면 라이벌 가게), 하늘색 점은 근처 자전거, 노란 `!`는 퀘스트를 주는 사람이에요.

자세한 기획은 [PRD.md](PRD.md)에 있어요.

# Brooklyn Streets

브루클린 거리를 배경으로 한 브라우저 3D FPS 게임 (Three.js).

## 실행

`index.html`을 브라우저로 열면 됩니다. (Three.js를 CDN에서 불러오므로 인터넷 연결 필요)

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 |
| Shift | 달리기 |
| Space | 점프 |
| 마우스 | 시점 |
| 좌클릭 / 우클릭 | 사격 / 정조준 |
| R | 재장전 |
| C | 크루 관리 (이름·색, 동료 영입) |
| E | NPC와 대화 / 보데가 가게 열기 |
| F | 손전등 켜기/끄기 (밤에는 자동으로 켜짐) |
| Esc | 일시정지 |

쓰러진 적이 떨어뜨린 노란 상자는 탄약, 초록 상자는 체력입니다.

## 게임 목표

라이벌 크루 3개(레드 후드 · 아이언 재킷 · 틸 킹스)를 몰아내고 브루클린 9개 구역을 점령한 뒤, 브루클린 브리지 아래에 나타나는 보스 3명을 쓰러뜨리면 "브루클린 통일" 엔딩입니다.

- 평판으로 동료를 영입하고(C), 보데가에서 보급품을 사세요(E).
- 피자집에서 배달 일을 받을 수 있어요.
- 총을 많이 쏘면 경찰이 출동합니다. 숨거나 지하철로 따돌리세요.
- 밤에는 적의 시야가 짧아지지만 손전등을 켜면 들키기 쉬워요.
- 지하철 노선도에서 내 구역 역으로 순간 이동할 수 있어요.

자세한 기획은 [PRD.md](PRD.md)에 있어요.
